# 0003. キャッシュ前提で描画する

## 文脈

セクションの内容は Jira REST への問い合わせで得るが、その応答は速くない。

## 決定

セクションはまずローカルキャッシュ（`~/.cache/jira-dash/`）から描画し、裏で
最新の内容を取得して更新する。キャッシュのキーはセクションのタイトルではなく
クエリ（JQL）にする。

## 理由

- Jira REST の1回の呼び出しは、Jira 側のサーバレイテンシが支配的で 0.5〜1.2s
  かかる（実測）。これは0001でプロセス起動コストを消したあとも残る、API 呼び出し
  そのもののコストである
- キーをクエリにしているので、タブ名を変えてもキャッシュは生き、JQL を変えれば
  自然に別キーになる

## 結果（トレードオフ・限界）

- 起動直後や更新直後の描画は最新でない場合がある（裏の取得が終わるまで）
