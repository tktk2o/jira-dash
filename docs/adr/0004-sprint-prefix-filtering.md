# 0004. `sprintPrefix` で取得後に前方一致する

## 文脈

ボードが複数チームのスプリントを同時に走らせている場合、見たいのは自分のチームの
スプリントだけだが、JQL 側にはそれを表現する手段が乏しい。

## 決定

`sprintPrefix` を設定に持たせ、JQL で取得したあとにアプリ側でスプリント名の
前方一致でフィルタする。

## 理由

- JQL の `sprint` には LIKE 相当の演算子が無い。`sprint ~ "Team"` を実際に試したところ
  15件中2件しか返らず、部分一致の代わりにならなかった
- active スプリントは毎イテレーションで改名されるため、名前の完全一致も使えない
- 前方一致は取得後にアプリ側で適用するしかないため、**そのセクションの `limit` は
  絞る前の件数を覆う必要がある** — limit を絞った後にフィルタすると、本来表示すべき
  行が limit の外に落ちて消える

## 結果（トレードオフ・限界）

- `limit` を「フィルタ後に見せたい件数」ではなく「フィルタ前に取得すべき件数」として
  設定する必要があり、他の（`sprintPrefix` を使わない）セクションと `limit` の意味が
  変わる
