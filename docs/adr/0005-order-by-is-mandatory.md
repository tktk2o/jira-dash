# 0005. JQL に `ORDER BY` を必ず書く

## 文脈

セクションの JQL に明示的な並び順を書かないセクションがあった。

## 決定

すべてのセクションの JQL に `ORDER BY` を書くことを前提とする。

## 理由

- Jira の暗黙の並び順はプロジェクト単位である。総数が `limit` を超えると、
  あるプロジェクトの課題が丸ごと下に沈んで消えることがある
- 実測: 63件のセクションで、あるプロジェクトの課題が全部52行目以降だった
  （`limit` の外に落ちていた）

## 結果（トレードオフ・限界）

- `ORDER BY` を書き忘れても構文エラーにはならず、症状は「一部のプロジェクトの
  課題だけが消えている」という気づきにくい形で出る
