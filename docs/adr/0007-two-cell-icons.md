# 0007. アイコンは全て2セル幅に揃える

## 文脈

課題タイプを表すアイコンに絵文字を使っている。絵文字の描画幅は文字によって
1セルまたは2セルとまちまちになりうる。

## 決定

使用するアイコンは全て2セル幅のものに揃える。

## 理由

- 1セル幅の絵文字を混ぜると、課題タイプによって右側の列がずれる
- `⚙️`（異体字セレクタ付き）と `🗂` は runewidth のライブラリで1セルとして
  計算されることを確認した。これらは候補から外す必要がある

## 結果（トレードオフ・限界）

- 使える絵文字の選択肢は「見た目が2セル幅として計算されるもの」に絞られる。
  candidate を増やすたびに runewidth での計算幅を確認する必要がある
