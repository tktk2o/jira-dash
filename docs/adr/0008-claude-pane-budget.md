# 0008. `jhd-claude-split` はスクリプトで、ペインは最大2枚まで

## 文脈

`prompt: true` のキーから Claude Code を起動するとき、Claude Code は alternate
screen を使う全画面 TUI なので、jhd の下端の枠に収めることができない
（枠に収めるには jhd 自身が PTY を持ってターミナルエミュレータになる必要がある）。
tmux のペインとして並べるしかなく、その割り方の判断（何枚まで許すか、どちら向きに
割るか、tmux の外で呼ばれたらどうするか）が必要になった。

## 決定

ペインの割り方を `scripts/jhd-claude-split`（tmux 操作のシェルスクリプト）に
切り出し、Claude 用のペインは最大2枚までとする。3枚目は拒否してステータス行に
理由を出す。tmux の外で呼ばれた場合も拒否する。

## 理由

- **スクリプトである理由**: `-v`（縦割り）と `-h`（横割り）のどちらを選ぶかは
  既に開いているペイン枚数を知る必要があり、拒否には理由を言う場所が必要になる。
  どちらもキーバインドのテンプレート文字列には収まらない。かつ、どちらも jira-dash
  本体に置くべきではない（jira-dash は tmux の存在を知らない）
- **2枚目が1枚目を割る理由**: 1枚目は jhd を下に割って作る。2枚目は jhd ではなく
  **1枚目**を横に割る。これにより jhd の表示は一切影響を受けない
- **3枚目を拒否する理由**: 実測で `-v` の素の連続実行によりペインの行数が
  45→22→11→5→2 と縮んでいくことを確認した。2行になると tmux は描画内容の
  下端しか表示できず、タブ帯・区切り線・列見出しがすべて画面外に出る。ダッシュボード
  として機能しなくなる境界が2枚目と3枚目の間にあるため、そこで止める
- **tmux の外を拒否する理由（フォールバックにしない理由）**: `tmux split-window`
  は `$TMUX` が無くても実行が成功してしまい、動いている別サーバの無関係な
  ウィンドウを割ってしまうことを実測で確認した。フォールバック動作にすると
  想定外のウィンドウが割られるので、拒否が正しい

## 結果（トレードオフ・限界）

- tmux 専用。tmux の外（他のマルチプレクサや単純な端末）では使えない
- ペインを閉じて枠を空ける操作は利用者に委ねている（tmux のペイン単位ユーザ
  オプションで印を付けているだけで、明示的な解放処理は無い）
