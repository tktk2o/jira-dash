# 0009. `{{.Prompt}}` と `{{.Input}}` を分ける

## 文脈

`prompt: true` のキーで打った文字を渡す先には、少なくとも2つの正反対な用途が
ある。Claude に相談する用途と、Jira へコメントとして投稿する用途である。

## 決定

打った文字を渡す変数を2つに分ける。`{{.Prompt}}` は課題キー・タイトル・本文・
区切り・打った文字を含めたもの、`{{.Input}}` は打った文字だけ。

## 理由

- Claude には課題の文脈を**含めて**渡したいが、コメントの投稿は**本文だけ**を
  送らないといけない
- 課題はすでにコメント先であり、それを本文に混ぜて `jira comment add` に渡すと、
  課題のタイトルや本文までコメントとして Jira に載ってしまう。これは一度混同すると
  Jira 側に残ってしまう（削除以外に取り消す手段が無い）操作なので、変数を分けて
  型で区別する

## 結果（トレードオフ・限界）

- 設定を書く側が `{{.Prompt}}` と `{{.Input}}` を取り違えるとこの事故が起きる。
  変数名を分けている以上の防止策（実行時の警告など）は無い
- `{{.Prompt}}` に本文を同梱するのは、プレビューが既に取得済みの場合に限る。
  取得前に押すとタイトルと指示だけになる
